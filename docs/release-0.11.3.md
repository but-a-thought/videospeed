# Release 0.11.3

## Features

- Added a hover-only save button for the draggable speed controller. Saved pixel offsets are restored per website, remain compatible with player-specific Custom CSS, and stay on the current device.
- Added Advanced settings controls to review, remove, or clear saved controller positions.

## Privacy

- Documented that explicitly saved website hostnames and controller offsets remain in browser-local extension storage and are never synchronized or transmitted.
